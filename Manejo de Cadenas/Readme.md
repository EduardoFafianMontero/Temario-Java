# Manejo de Cadenas

## 📌 Sobre esta carpeta

Trabajo con `String` en Java: crearlas, concatenarlas, y acceder a caracteres concretos dentro de una cadena.

Está dividida en dos subcarpetas:

- **[Ejercicios/](./Ejercicios)** — Prácticas que voy haciendo sobre lo visto en teoría.
- **[Temarios/](./Temarios)** — Apuntes y notas de los conceptos de este tema.

## 📂 Ejercicios

- **[manejo de cadenas](./Ejercicios/manejo%20de%20cadenas)** — Crear `String` como literal y con `new String()`, concatenación y *text blocks*.
- **[indice de cadenas](./Ejercicios/indice%20de%20cadenas)** — Acceder a un carácter concreto de una cadena por su índice con `charAt()`.
- **[Comparación de cadenas](./Ejercicios/Comparaci%C3%B3n%20de%20cadenas)** — Diferencia entre comparar `String` con `==` (referencia) y con `.equals()` (contenido).
- **[Método de Cadenas](./Ejercicios/M%C3%A9todo%20de%20Cadenas)** — Métodos más comunes de `String`: `length()`, `replace()`, `toUpperCase()`, `toLowerCase()` y `trim()`.
- **[Manejo Subcadenas](./Ejercicios/Manejo%20Subcadenas)** — Extraer parte de una cadena con `.substring(inicio, fin)`.

*(Esta lista se irá ampliando a medida que añada más ejercicios.)*
