# Variables

## 📌 Sobre este ejercicio

Ejercicio base sobre declaración de variables en Java, usando los 4 tipos de dato más comunes.

## 🔤 Variables declaradas

| Variable | Tipo | Valor inicial | Significado |
| :--- | :--- | :--- | :--- |
| `edad` | `int` | `31` | Tipo de dato entero |
| `precio` | `double` | `300.4` | Tipo de dato decimal |
| `disponible` | `boolean` | `true` | Valor `true`/`false` |
| `genero` | `char` | `'M'` | Un solo carácter — `M` (Masculino) / `F` (Femenino) |

## 🧩 Qué hace el código

1. Declara las 4 variables con su valor inicial.
2. Imprime `edad` por consola.
3. Modifica `edad` (pasa de `31` a `35`), demostrando que una variable puede reasignarse tras su declaración.
4. Imprime el resto de variables (`precio`, `disponible`, `genero`).

## 💻 Compilar y ejecutar

```bash
javac Variables.java
java Variables
```
