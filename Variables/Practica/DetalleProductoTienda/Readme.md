# DetalleProductoTienda

## 📌 Sobre este ejercicio

Declaración de variables para representar el detalle de un producto de una tienda: nombre, precio, cantidad en stock y disponibilidad.

## 🧩 Qué incluye

| Variable | Tipo | Valor | Significado |
| :--- | :--- | :--- | :--- |
| `NombreProducto` | `String` | `"Camara"` | Nombre del producto |
| `PrecioProducto` | `double` | `800.99` | Precio |
| `CantidadProducto` | `int` | `5` | Unidades en stock |
| `Disponible` | `boolean` | `true` | Si está disponible para la venta |

## 💻 Compilar y ejecutar

```bash
javac DetalleProductoTienda.java
java DetalleProductoTienda
```

## 📝 Notas

- Las variables empiezan por mayúscula (`NombreProducto`, `PrecioProducto`...). Es válido en Java, pero por convención (ver el ejercicio [`Reglas de nombre`](../../Reglas%20de%20nombre)) lo recomendado es `camelCase` empezando por minúscula: `nombreProducto`, `precioProducto`, etc.
