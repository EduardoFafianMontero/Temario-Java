Arrays unidimensionales
(Fichero: ArraysUnidimensionales.java, clase pública ArraysUnidimensionales, con su propio método main.)
1. Declara un array de 6 números decimales llamado notas e inicializa cada posición con un valor distinto entre 0 y 10 (cada valor tendrá dos decimales).
2. Recorre el array con un bucle for y muestra por consola cada nota junto con su posición.
3. Calcula y muestra la suma y la media de todas las notas del array.
4. Declara un segundo array de tipo String con los nombres de 4 compañeros o compañeras, inicializándolo directamente con {...}, y muéstralo recorriéndolo con un bucle for-each.
