Operadores aritméticos, relacionales y lógicos
(Fichero: OperadoresBasicos.java, clase pública OperadoresBasicos, con su propio método main.)
1. Escribe un programa que declare una variable para cada una de las siguientes expresiones, asignándole el resultado correspondiente, y que muestre después el valor de todas ellas por consola: 17 / 5, 17 % 5, 17.0 / 5, (10 > 5) && (3 < 1), (10 > 5) || (3 < 1), !(10 > 5).
2. Antes de ejecutar el programa, calcula a mano el resultado que esperas obtener de cada expresión, y comprueba después si coincide con lo que muestra la consola.
