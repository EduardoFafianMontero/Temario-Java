Conversión de tipos
(Fichero: ConversionTipos.java, clase pública ConversionTipos, con su propio método main.)
1. Declara una variable int con el valor 15 y asígnala a una variable double. Indica si necesitas o no conversión explícita.
2. Declara una variable double con el valor 9.75 y conviértela a int. ¿Qué valor obtienes? ¿Por qué?
3. Escribe un programa que declare dos números enteros, calcule su división y muestre el resultado tanto como número entero como número decimal, utilizando casting cuando sea necesario.
Ayuda: El operador / realiza la división. Si los dos operandos son enteros, el resultado es una división entera; si al menos uno es float o double, se obtiene un resultado decimal.
