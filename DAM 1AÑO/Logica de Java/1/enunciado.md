Actividad-ud02-02: Nuestro primer programa en Java
1. Crea un nuevo proyecto en IntelliJ llamado UD02-PrimerPrograma.
2. Dentro de la carpeta src, crea una clase llamada Main.
3. Escribe un programa que muestre por consola, usando
System.out.println(), tu nombre y el mensaje "¡Ya programo en
Java!", cada uno en una línea distinta.
4. Amplía el programa declarando dos variables: una de tipo String con tu
nombre, y otra de tipo int con tu edad. Utiliza esas variables para mostrar
por consola un mensaje de presentación, concatenando texto y variables (por
ejemplo: "Me llamo " + nombre + " y tengo " + edad + " años").
5. Ejecuta el programa desde IntelliJ y comprueba que el resultado por consola
es el esperado.
6. Localiza, dentro de la estructura de carpetas del proyecto, el fichero .class
generado tras la compilación, y anota en qué carpeta se encuentra
