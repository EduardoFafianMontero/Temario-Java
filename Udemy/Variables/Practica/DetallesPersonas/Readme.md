# DetallePersona

## 📌 Sobre este ejercicio

Práctica de declaración de variables usando como ejemplo el detalle de una persona: nombre, edad, estatura, país de origen y estado civil.

## 🔤 Variables declaradas

| Variable | Tipo | Valor | Significado |
| :--- | :--- | :--- | :--- |
| `nombre` | `String` | `"Eduardo"` | Nombre de la persona |
| `edad` | `int` | `21` | Edad en años |
| `estatura` | `double` | `1.70` | Estatura en metros |
| `PaisOrigen` | `String` | `"España"` | País de origen |
| `casado` | `char` | `'S'` | Estado civil — `S` (Sí) / `N` (No) |

## 🧩 Qué hace el código

1. Declara las 5 variables con el detalle de la persona.
2. Imprime cada una por consola con `System.out.println()`, en el mismo orden en que fueron declaradas.

## 💻 Compilar y ejecutar

```bash
javac DetallePersona.java
java DetallePersona
```
