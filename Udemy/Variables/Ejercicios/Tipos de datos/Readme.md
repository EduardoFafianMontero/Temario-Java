TiposDatos
📌 Sobre este ejercicio

Declaración de una variable de cada tipo de dato primitivo de Java (byte, short, int, long, float, double, char, boolean) y de un tipo de referencia (String), para ver su sintaxis, rango y uso típico.

El detalle de para qué sirve cada tipo está comentado directamente en el código, línea a línea.

💻 Compilar y ejecutar
bash
javac TiposDatos.java
java TiposDatos
📝 Notas
Los tipos primitivos siempre tienen un valor por defecto y nunca pueden ser null.
String es un tipo de referencia (un objeto), por eso puede valer null — algo que ningún primitivo puede hacer.
