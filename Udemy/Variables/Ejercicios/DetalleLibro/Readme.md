# DetalleLibro

## 📌 Sobre este ejercicio

Práctica de declaración y uso de variables en Java usando como ejemplo los datos de un libro: título, autor, número de páginas, precio, si está disponible, etc.

El objetivo es afianzar:

- Cómo se declara una variable (`tipo nombre = valor;`)
- Los tipos de datos básicos: `String`, `int`, `double`, `boolean`
- Cómo mostrar el valor de varias variables por consola con `System.out.println()`

## 💻 Compilar y ejecutar

```bash
javac DetalleLibro.java
java DetalleLibro
```

## 📝 Notas

- El nombre del archivo (`DetalleLibro.java`) coincide con el de la clase pública que contiene, como en el resto de ejercicios del repositorio.
