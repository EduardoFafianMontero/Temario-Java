# Sentencias de Decisión en Java

## 📌 Sobre esta carpeta

Sentencias condicionales: `if`, `else` y, más adelante, `switch` — cómo hacer que el programa tome decisiones según el valor de una variable.

Está dividida en tres subcarpetas:

- **[Ejercicios/](./Ejercicios)** — Prácticas que voy haciendo sobre lo visto en teoría.
- **[Practica/](./Practica)** — Ejercicios de práctica libre sobre este tema.
- **[Temario/](./Temario)** — Apuntes y notas de los conceptos de este tema.
