# Funciones en Java

## 📌 Sobre esta carpeta

Una **función** es un bloque de código con nombre que se escribe una vez y se llama las veces que haga falta. Aquí veo cómo definirlas, pasarles datos, hacer que devuelvan un resultado y cómo una función puede llamarse a sí misma (**recursividad**).

Está dividida en tres subcarpetas:

- **[ejercicio/](./ejercicio)** — Ejercicios que sigo del curso.
- **[Practica/](./Practica)** — Práctica libre sobre este tema *(pendiente)*.
- **[Temario/](./Temario)** — Apuntes y notas de los conceptos.

## 🧱 Las funciones de un vistazo

| Concepto | Ejemplo | Significado |
| :--- | :--- | :--- |
| Sin retorno | `static void saludar(String m)` | Hace algo, no devuelve nada |
| Con retorno | `static int sumar(int a, int b)` | Devuelve un `int` con `return` |
| Devuelve `boolean` | `static boolean esPar(int n)` | Responde `true` o `false` |
| Recursiva | `funcionRecursiva(numero - 1)` | Se llama a sí misma hasta el caso base |
