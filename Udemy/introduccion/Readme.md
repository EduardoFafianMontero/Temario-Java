# Introducción a Java

## 📌 Sobre esta carpeta

Primeros pasos con Java: estructura básica de una clase, el método `main` como punto de entrada, y cómo imprimir texto por consola.

## 📂 Ejercicios

- **HolaMundo** — Primer contacto con Java: estructura básica de una clase, el método `main` como punto de entrada, y `System.out.println()` para imprimir texto por consola.
- **Presentación** — Uso de varias instrucciones `System.out.println()` seguidas para presentarme (nombre, edad, país).
