# Segundo ejercicio en Java — Presentación

## 📌 Descripción

Este ejercicio consiste en una clase llamada `Presentación` que, dentro del método `main`, usa varias instrucciones `System.out.println()` seguidas para presentarme por consola: mi nombre, mi edad y mi país.

Con este ejercicio practico:
- Encadenar varias instrucciones `System.out.println()` seguidas dentro del mismo `main`, cada una imprimiendo una línea distinta.
- Usar texto (strings) con información personal como contenido de la salida por consola.
- Reforzar que cada clase pública va en su propio archivo `.java` con el mismo nombre (en este caso, `Presentación.java`).

## 💻 Comandos de terminal (compilar y ejecutar)

```bash
# 1. Compilar el archivo .java (genera un archivo .class)
javac Presentación.java

# 2. Ejecutar el programa ya compilado
java Presentación
```

> 💡 Nota: `javac` **compila** el código (lo traduce a bytecode) y `java` **ejecuta** la clase compilada. No hace falta poner la extensión `.class` al ejecutar, solo el nombre de la clase.
